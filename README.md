
# Invoice Processing Automation

An AI-powered invoice processing pipeline built with Python.

## Project Goals

- Retrieve invoice PDF attachments from Gmail.
- Extract text and structure invoice data using AI.
- Validate extracted data with Pydantic and business rules.
- Detect anomalies and potential duplicate invoices.
- Store invoice records in Airtable.
- Send Slack notifications when review is needed.
- Generate draft accounting entries in a mock QuickBooks structure.

## Status

Currently in development. Integrations and features will be implemented incrementally, with automated tests added throughout the project.
